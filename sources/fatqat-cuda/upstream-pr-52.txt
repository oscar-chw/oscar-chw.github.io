description (excerpt): On Python 3.12 there is no os.process_cpu_count, so _process_worker_ceiling falls back to os.cpu_count(), which counts every core of the machine even when the process is pinned (taskset) or CPU-limited (a container cpuset); process shot workers were sized to every core of the machine and oversubscribed them. This change uses os.sched_getaffinity(0) where os.process_cpu_count is missing (Linux), and keeps os.cpu_count() elsewhere. Python 3.13+ is unchanged. The test resolves a process-shot policy with process_cpu_count absent and checks the worker limit follows the affinity mask.
