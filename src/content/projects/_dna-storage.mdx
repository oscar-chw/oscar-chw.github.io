### The problem

DNA can hold data for a very long time in very little space, but writing and reading it is noisy in a way disks are not. Besides wrong letters (substitutions), the chemistry drops letters (deletions), adds letters (insertions) and loses whole strands (erasures). An insertion or deletion shifts every letter after it, so codes built for wrong letters alone cannot recover the data.

### What I built

- **An encoder** that maps data into DNA strings, a reversible two-bits-per-letter mapping, plus a separate visualisation that reports GC content and long runs of one letter.
- **Noisy-channel simulations** with substitutions, insertions, deletions and erasures. The Python simulations expose seeds; the repository's standalone browser demo draws fresh random errors.
- **Three ways back**: Reed–Solomon codewords for substitutions and erasures, LT-style fountain codes decoded by belief propagation for lost strands, and a simplified HEDGES-style beam search for insertions and deletions.
- **Eight figures and an interactive browser demo**, so each stage can be seen, not only read about. An individual project in a group-based course.

### Result

These are synthetic teaching simulations, not physical storage experiments. The Python figures use seeded channels; the repository's standalone browser demonstration uses fresh randomness, so its noisy runs are not reproducible by seed. This site's DNA channel is a separate, seeded illustration. No measured physical-storage performance is claimed.

### Limits

- The HEDGES-style decoder is a simplified custom beam search, not the published HEDGES algorithm.
- The Reed–Solomon figure encodes codewords but does not run a decoder, and its seeded case (two erasures plus one unknown error) is outside the RS(10,7) correction bound.
- The fountain example is a construction check, not a robustness measurement, and the bits-per-letter curve is a hand-coded reference for plotting, not a measurement.
- The GC illustration is not a balancing codec: complementing A/T and C/G cannot change the GC fraction.
