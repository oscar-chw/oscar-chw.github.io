

### The problem

Planning a CUHK timetable means juggling sections, clashes and course search across several university pages. Our software engineering course team set out to put all of it in one place.

### What I built

I initiated the project, led its architecture and made the most commits (141 of 290), across the React/TypeScript frontend and the Express/Prisma backend:

- the timetable planner: add and drop, with conflict checks and image export;
- course search and import;
- an admin dashboard with role-based access control;
- English and Chinese interfaces;
- one-command setup scripts.

### Result

A working planner, delivered with the team over one term (Feb – May 2025).

### How it works

A React/TypeScript single-page app talks to an Express REST API. Prisma maps the API to the database, and role-based access control guards the admin routes.

### Limits

- The repository is private and owned by a teammate, so there is no public code link.
