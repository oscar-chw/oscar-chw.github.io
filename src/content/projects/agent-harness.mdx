## The problem

Every AI coding tool keeps its own instruction file. None of them share memory, and they forget between sessions, so they repeat the same mistakes. And a tool running with broad permissions can execute a destructive command.

## What I built

- **One rulebook, translated per tool**, so the tools cannot drift apart. It stays short because it is paid for in every request.
- **Shared memory and retrieval over MCP**, including search over past session transcripts.
- **A command guard for Claude Code** that parses each shell command and fails closed.
- **A keep rule**: features that showed no measured gain ship off by default.

**Why fail closed:** the guard blocks any command it cannot parse. A false block costs the user one question. A missed delete of the home directory cannot be undone.

<p class="comment">designed and verified by Oscar, implemented with AI coding agents (Claude Code, Codex)</p>

## Limits

- The guard is a seat belt, not a sandbox, and has known gaps.
- The evaluation was small and ran on a private corpus. Only some of the supported tools were measured.
